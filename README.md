Ini project yang saya buat:
Deskripsi Umum Website
Website LOBUDA merupakan sebuah website toko kopi atau café yang dibuat untuk memperkenalkan café serta menampilkan berbagai pilihan menu minuman kepada pelanggan. Website ini dirancang dengan tampilan sederhana, modern, dan menarik menggunakan HTML sebagai struktur utama serta Tailwind CSS untuk mengatur desain dan tata letak website.

Website LOBUDA memiliki tema warna cokelat bata, putih, dan warna" pendukung lainnya yang memberikan kesan hangat, nyaman, dan sesuai dengan konsep sebuah café.

Website ini bertujuan untuk memudahkan pelanggan dalam melihat daftar menu, mengetahui harga minuman, membaca deskripsi produk, serta mendapatkan informasi mengenai café dan kontak yang dapat dihubungi.
